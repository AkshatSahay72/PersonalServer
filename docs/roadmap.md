# PersonalServer Future Roadmap

Following the successful completion of **PersonalServer v1.0**, future milestones will expand on this foundation.

---

## 1. Milestone Evolution

- **v0.3–v0.5**: Remote Access, Process Orchestration, Node Agent. *(Complete)*
- **v0.6–v0.7**: Multi-Node Registration, Cluster Membership. *(Complete)*
- **v0.8–v0.9**: Workload Execution, Resource-Aware Scheduling. *(Complete)*
- **v1.0**: Reliable Jobs + Storage Subsystem + Operations Web UI. *(Complete & Verified)*

---

## 2. Planned Future Directions (v1.1+)

1. **Distributed / Multi-Node Storage**: Expanding storage across secondary storage nodes with metadata federation.
2. **Streaming Telemetry & WebSockets**: Real-time live metrics and terminal streaming in the web UI.
3. **Automated Backup Snapshots**: Lightweight incremental backups of `~/PersonalServer/storage/`.
4. **Hardware Acceleration Detection**: Automated detection of NPU/GPU compute capabilities on Android devices.
